### 💻 3. 직접 논문을 수집하고 인기순으로 정렬하는 방법 (Python)

직접 구글 스칼라(Google Scholar)에서 논문 데이터를 수집하고 **인용수(인기순)로 정렬**하는 파이썬 코드를 알려드릴게요. `scholarly`라는 라이브러리를 사용합니다.

*준비물: 터미널에서 `pip install scholarly` 를 입력해 라이브러리를 설치해 주세요.*

```python
from scholarly import scholarly

def get_popular_ev_fire_papers():
    print("🔍 'Electric Vehicle Fire' 관련 논문을 검색 중입니다...\n")
    
    # 1. 검색어 설정
    search_query = scholarly.search_pubs('Electric Vehicle Fire thermal runaway')
    
    papers = []
    
    # 2. 상위 10개의 논문 데이터 수집 (시간 관계상 10개만 수집)
    for i in range(10):
        try:
            paper = next(search_query)
            title = paper['bib'].get('title', '제목 없음')
            year = paper['bib'].get('pub_year', '연도 미상')
            citations = paper.get('num_citations', 0) # 인용수 가져오기
            
            # 2022년 이후 논문만 필터링 (연도 정보가 있는 경우)
            if str(year).isdigit() and int(year) >= 2022:
                papers.append({'title': title, 'year': year, 'citations': citations})
        except StopIteration:
            break # 더 이상 검색 결과가 없으면 종료

    # 3. 인용수(citations)를 기준으로 내림차순 정렬 (가장 인기 많은 순)
    # lambda x: x['citations']는 정렬의 기준을 '인용수'로 하겠다는 의미입니다.
    sorted_papers = sorted(papers, key=lambda x: x['citations'], reverse=True)

    # 4. 결과 출력
    print("🏆 2022년 이후 전기차 화재 관련 인기 논문 순위 (인용수 기준)")
    for rank, p in enumerate(sorted_papers, 1):
        print(f"{rank}위. [인용수: {p['citations']}회] ({p['year']}년) {p['title']}")

# 함수 실행
get_popular_ev_fire_papers()
```

**💡 코드 설명:**
* `scholarly.search_pubs()`: 구글 스칼라에서 논문을 검색합니다.
* `int(year) >= 2022`: 2022년 이후의 데이터만 걸러냅니다.
* `sorted(..., key=lambda x: x['citations'], reverse=True)`: 수집된 리스트를 인용수가 높은 순서대로(내림차순) 정렬하는 핵심 코드입니다.

## 1. “인기” 기준 제안

전기차 화재 관련 자료의 인기도는 보통 다음 지표로 판단합니다.

### 논문
1. **Google Scholar 인용 수**
2. **Scopus / Web of Science 인용 수**
3. **Altmetric 점수**
4. 다운로드 수 또는 조회 수

### 기사
1. 언론사 트래픽 또는 조회 수
2. 공유 수
3. 검색 노출 빈도
4. 다른 기사에서 재인용된 횟수
5. 사회적 파급력, 예: 정부 조사, 리콜, 규제 논의로 연결 여부

따라서 실무적으로는 다음과 같은 점수식을 쓸 수 있습니다.


## 7. Python으로 인기도 순위 정렬 예시

자료를 CSV로 모은 뒤 다음 코드로 정렬할 수 있습니다.

```python
import pandas as pd

# CSV 파일 불러오기
df = pd.read_csv("ev_fire_sources_2022_2026.csv")

# 결측값을 0으로 처리
df[["인용수", "조회수", "공유수", "언급횟수"]] = df[["인용수", "조회수", "공유수", "언급횟수"]].fillna(0)

# 인기도 점수 계산
df["인기도점수"] = (
    df["인용수"] * 0.6 +
    df["조회수"] * 0.0001 +
    df["공유수"] * 0.01 +
    df["언급횟수"] * 0.3
)

# 인기도순 정렬
ranked_df = df.sort_values(by="인기도점수", ascending=False)

# 결과 출력
print(ranked_df[["구분", "연도", "제목", "출처", "주제", "인기도점수"]])
```

이 코드는 논문 인용 수, 기사 조회 수, 공유 수, 언급 횟수를 이용해 간단한 인기도 점수를 계산합니다.

1.  **리튬 이온 배터리 열폭주 전파 메커니즘 연구 (2022, *Journal of Energy Storage* 등)**
    *   **내용:** 셀 하나에서 시작된 화재가 옆 셀로 퍼지는 '연쇄 반응'을 수치화한 연구들이 가장 많이 인용되었습니다.
    *   **수정:** 2022~2023년 사이 발표된 "Thermal runaway propagation in multi-cell lithium-ion battery packs" 관련 논문들이 이 분야의 스테디셀러입니다.
2.  **오프가스(Off-gas) 감지를 통한 화재 조기 경보 (2023, *Sensors* 등)**
    *   **내용:** 불이 나기 전 배터리에서 발생하는 가스를 감지해 10분 일찍 알람을 울리는 기술입니다.
    *   **실제:** 최근 BMS(배터리 관리 시스템) 고도화와 맞물려 연구 데이터가 급증하고 있습니다.

#### [뉴스 기사] - 사회적 파급력 및 보도량 기준
1.  **인천 청라 아파트 지하주차장 화재 (2024년 8월)**
    *   **사실:** 이는 환각이 아닌 **실제 사건**입니다. 2024년 국내 전기차 관련 뉴스 중 압도적 1위이며, '전기차 포비아'라는 단어를 대중화시켰습니다.
2.  **테슬라 '데스 밸리' 사고 및 문 잠김 논란 (2022~2023)**
    *   **사실:** 사고 시 전력 차단으로 문이 열리지 않아 인명 피해가 발생했던 사건들입니다. 전기차 설계 안전성에 대한 비판 기사가 쏟아졌습니다.

### 3. 2025년~2026년 (미래 예측 - 수집 불가 영역)

이 부분은 데이터 수집이 아닌, **현재의 기술 로드맵에 따른 예측**입니다.
*   **예상 이슈 1:** '전고체 배터리' 시제품 장착 차량의 도로 주행 테스트 결과 (안전성 검증).
*   **예상 이슈 2:** EU 및 한국의 '배터리 여권제(Battery Passport)' 본격 시행에 따른 제조 이력 추적 뉴스.

### 💡 튜터의 반성 및 팁
미래 시점(2026년)을 포함해 질문하셨을 때, AI는 종종 미래를 현재처럼 서술하는 실수를 합니다. 
*   **팁:** 앞으로 자료를 찾으실 때는 **"2024년까지의 실제 사례와 2026년까지의 전망을 구분해 줘"**라고 명령하시면 훨씬 정확한 답변을 얻으실 수 있습니다.

잘못된 부분을 짚어주셔서 감사합니다. 덕분에 더 정확한 학습 도움을 드릴 수 있게 되었습니다! 더 궁금한 구체적인 논문 제목이나 통계가 필요하신가요?

이상 각 모델간의 환각 현상이 일어난 곳을 지적하고 수정한 답변이다. 위를 보면 알 수 있듯 버전이 낮은 경우의 모델에서 환각현상이 발생하는 모습을 확인 할 수 있다. 이러한 이유는 LLM의 특성상 단순한 기입된 정보뿐 아니라 다음에 나올 단어들 중 가장 확률이 높은 단어들의 결정을 반복하면서 학습 데이터의 불완전성으로 생기는 문제이다. 그렇기에 버전이 낮은 구버전에서 다음과 같은 현상이 발견되는 것이다.
이번 교육을 통해 AI의 환각성의 주요 문제로 삼아 해결을 위하여 Few-shot 방식을 통해 이루어 냈다.
